# Reporting a vulnerability

Please report suspected security vulnerabilities privately through
[GitHub's private vulnerability reporting](https://github.com/reisfe/typesafer/security/advisories).
Select **Report a vulnerability** and include the package version, steps to
reproduce the problem and its potential impact. Do not include API keys or
other sensitive data.

Please avoid public issues for security vulnerabilities. Use public GitHub
issues for ordinary bugs and feature requests.
